# Dimitry Hub 1.0

Aplicación de escritorio para Windows con estudio, investigación, Palworld, análisis técnico, proyectos, archivos e integración de IA.

## Actualizaciones
La aplicación consulta el canal oficial `DimitryUwU/Dimitry-Hub-Releases`, verifica SHA-256 y conserva los datos en `%LOCALAPPDATA%\Dimitry Hub\Data`.
